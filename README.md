# 💎 Diamond Shop

A modern, fully responsive **e-commerce website** built with **HTML5**, **CSS3**, **Bootstrap**, and **Vanilla JavaScript**.  
This project provides a complete shopping experience including product browsing, shopping cart, user authentication, and a gift section — all without any backend framework.

---

## ✨ Features

- 🏠 **Home Page** — Attractive landing page with product highlights
- 🛍️ **Product Pages** — Multiple dedicated pages for different products
- 🛒 **Shopping Cart** — Add, view, and manage selected items (Sabad Kharid)
- 🔐 **Authentication** — Login and Register pages
- 🎁 **Gift Section** — Special page for gift items
- 📱 **Fully Responsive** — Optimized for mobile, tablet, and desktop
- 🎨 **Custom Fonts & Styling** — Beautiful Persian typography
- ⚡ **Lightweight & Fast** — Pure HTML/CSS/JS, no build tools needed

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Semantic page structure |
| CSS3 | Custom styling & animations |
| Bootstrap | Responsive grid & UI components |
| JavaScript (Vanilla) | Interactivity & cart logic |
| Custom Fonts | Persian typography |
